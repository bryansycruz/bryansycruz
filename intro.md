## Como usar este recurso

1. **Lee** los modulos en orden o navega por el tema que necesites usando la barra lateral izquierda.
2. **Clona** el repositorio para ejecutar los notebooks en tu maquina:

 ```bash
 git clone https://github.com/bryansycruz/bryansycruz.git
 cd bryansycruz
 pip install -r requirements.txt
 ```

3. **Abre** cualquier notebook con Jupyter:

 ```bash
 jupyter notebook
 ```

4. O **lanza directamente en Google Colab** usando el boton en cada pagina.
